# Security Policy

## Supported scope

This repository contains local training and inference code for French text correction.

## Reporting a problem

If you find a security issue in the code, data pipeline, or release process:

- open a private GitHub security advisory when possible, or
- contact the repository maintainer through GitHub.

Please include:

- the affected file or script
- a short reproduction path
- whether the issue affects training data, model output, or local execution

## What not to report publicly

- generated model weights
- training logs
- sample corpora content that is already publicly shipped in the repository
