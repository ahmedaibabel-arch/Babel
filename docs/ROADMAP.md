# Roadmap

## Current direction

Keep Babel as a local French correction system with strict JSON output and a lightweight runtime.

## Near-term work

- stabilize the dataset generation pipeline
- improve hard-negative coverage
- keep the adapter small enough for local Apple Silicon use
- refine evaluation and regression probes

## Later work

- package the runtime for easier integration in writer workflows
- add more regression tests for typography and agreement
- document model selection and checkpoint promotion
